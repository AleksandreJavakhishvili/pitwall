# Platform services

**Preview.** Coming in the SDK preview. This page will describe what Pitwall gives every tile, so authors don't build it themselves.

## What this page will cover

- `tasks`: timers and background work, paused while the tile is hidden.
- `storage`: a key-value store for the tile's own data, and its size limit.
- `settings`: settings and secrets in a form Pitwall draws.
- How further services are added: only when a tile can't reasonably do without one.

Until then, the [overview](README.md) describes what a tile is.
