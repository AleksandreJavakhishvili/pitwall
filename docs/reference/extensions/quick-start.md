# Extensions quick start

**Preview.** Coming in the SDK preview. This page will take you from an empty folder to a tile running in Pitwall.

## What this page will cover

- Installing the Rust target the SDK needs (`wasm32-wasip2`).
- Scaffolding a tile with `pitwall extension new` and what the new project holds.
- Running it live with `pitwall extension dev`: a rebuild on every save, the tile reloaded in Pitwall with its state kept, and its Log in your terminal.
- Checking it with `pitwall extension check`.
- Sharing a preview tile with `pitwall extension install`, and what the person you share it with sees.

Until then, the [overview](README.md) describes what a tile is.
