# WIT reference 0.1

**Preview.** Coming in the SDK preview. This page will list every interface, type and function of the tile world, version 0.1: the contract between a tile and Pitwall, written in WIT (the WebAssembly Interface Type language).

## What this page will cover

- The tile world: what a tile exports to Pitwall and what it imports from it.
- Each interface of WIT 0.1 (box, text, button, icon, scroll, input, events, ui, log, and the platform services `tasks`, `storage` and `settings`) with its records, variants, enums and functions.
- The doc comment of each item, as written in the WIT.

The site build generates the reference from the WIT's doc comments, so it can't disagree with the WIT. Until then, the [overview](README.md) describes what a tile is.
