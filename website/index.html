A permission prompt or a question turns the agent amber, sorts it to the top and lights the bar along the bottom. ⌘J jumps there.

Every terminal, live, grouped by project, the ones that need you first. The Wall only watches; click a tile to take over.

Queue the next instruction while the agent works. It goes in exactly as written once the agent is done or idle.

What each agent changed, task by task. Comment on lines, send them back as one prompt, merge when you click.

⌘T opens a terminal in the focused agent's folder. Start claude or codex in it and the pane becomes that agent, with its flag and Next up.

One rule library, written into CLAUDE.md, AGENTS.md and the rest through rulesync. Generated files stay out of your diffs.
