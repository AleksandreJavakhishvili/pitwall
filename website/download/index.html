Download

Pitwall for macOS, Windows and Linux. Free and open source under Apache-2.0. Early builds, not code-signed yet: each card says what the first launch looks like.

macOS

Your system

Apple silicon and Intel, one universal build.

  • Download .dmg Pitwall_<version>_universal.dmg
  • App bundle (.tar.gz) Pitwall_<version>_universal.app.tar.gz

First launch

  1. Open the .dmg and drag Pitwall to Applications.
  2. The app isn't signed with an Apple Developer ID yet, so a double-click is blocked the first time. Right-click Pitwall.app → Open, then Open again. Or: System Settings → Privacy & Security → Open Anyway.
  3. If macOS says the app is damaged, clear the quarantine flag: 
    xattr -dr com.apple.quarantine /Applications/Pitwall.app
  4. Reading projects in Desktop or Documents makes macOS ask for folder access. The welcome screen offers Full Disk Access instead; until builds are signed, macOS may ask again after an update.

Windows

Your system

Windows 10 1809+ or 11, x64. New and less tested than macOS.

Coming in a later release. Watch Releases on GitHub for it.

  • Download installer Pitwall_<version>_x64-setup.exe · per user, no admin
  • .msi package Pitwall_<version>_x64.msi

First launch

  1. The builds aren't code-signed yet, so SmartScreen shows "Windows protected your PC": click More info → Run anyway.
  2. Check the download against SHA256SUMS.txt first: 
    Get-FileHash .\Pitwall_*_x64-setup.exe
  3. The installer fetches the WebView2 runtime if it's missing. Closing the window keeps Pitwall in the tray.

Linux

Your system

x86_64, glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 or newer).

  • Download AppImage Pitwall_<version>_amd64.AppImage
  • .deb package Pitwall_<version>_amd64.deb

First launch

  1. AppImage, any distribution (needs FUSE 2: libfuse2, or libfuse2t64 on Ubuntu 24.04): 
    chmod +x Pitwall_*_amd64.AppImage
./Pitwall_*_amd64.AppImage
  2. Debian, Ubuntu and derivatives; installs the WebKitGTK 4.1 dependencies too: 
    sudo apt install ./Pitwall_*_amd64.deb
  3. Hooks reach Pitwall through curl; the .deb depends on it, with the AppImage install it if it's missing.

Build from source

Rust, Node.js 20.19+ and pnpm plus the Tauri 2 prerequisites for your platform. Steps for each OS, including the Linux packages, are in the quick start and the README.

git clone %REPO_URL%.git
cd pitwall
pnpm install
pnpm tauri build

A Homebrew cask is coming; it isn't published yet. This page asks GitHub's API for the latest release; nothing else is loaded from third parties.
