# Security

To report an extension that is harmful (malware, stolen tokens, hidden
behaviour), open a report from Pitwall (an extension's page → Report a
problem → It does something harmful), or write privately to
SECURITY_ADDRESS if it shouldn't be public yet.

Maintainers can block a version or an extension in `blocked.toml`; Pitwall
turns blocked copies off at its next daily check and says why.

A suspected compromise of the index itself (its signing key, this
repository, a maintainer's account): write privately to SECURITY_ADDRESS.
